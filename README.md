# 🌸 M120Launcher <3

> A lightweight, custom, pastel-pink & lavender Android launcher specially crafted for the **Chinoe AT-M120** flip phone (and other low-resource / compact portrait devices)! ✨

---

## 🎀 Features & Highlights

- **🌸 Kawaii Aesthetic**: Built with Jetpack Compose featuring a cozy pastel pink and lavender color palette, custom cards, and playful `StickerExplosion` decorations.
- **📱 Tailored for 480x800 Portrait**: Optimized specifically for compact flip phones and small touchscreens.
- **⚡ Lightweight & Resource-Efficient**: Carefully tuned for low-RAM hardware (running smoothly around ~162 MB PSS on MediaTek MT6761 / 2GB RAM devices).
- **📂 App Drawer & Favorites**: Quick access to your favorite apps with easy reordering, icon search, and smooth swipe gestures.
- **🎨 Wallpaper & Icon Customization**:
  - Sampled wallpaper loading & reset support.
  - Automatic `KAWAIIICON` mapping.
  - Manual icon selection and custom app icons with reset capability.
- **🔋 Handy Status Card**: Clean status widget showing battery, Wi-Fi, and time at a glance.
- **🏠 Seamless Home Integration**: Full HOME launcher behavior with physical Home button support returning straight to your cozy home state.

---

## 🛠️ Tech Stack & Target Device

- **Target Device**: Chinoe AT-M120 (Android 12, ARMv7 / `armeabi-v7a`)
- **Hardware Profile**: 480 x 800 portrait display, ~2 GB RAM, MediaTek MT6761
- **UI Toolkit**: Jetpack Compose (Material 3 inspired / custom pastel styling)
- **Language**: Kotlin

## 🚀 Getting Started & Building

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/M120Launcher.git
   ```
2. **Open in Android Studio**:
   Open the project root directory in Android Studio.
3. **Build & Run**:
   Connect your device or emulator (configured for 480x800 portrait) and build the app:
   ```bash
   ./gradlew assembleDebug
   ```
