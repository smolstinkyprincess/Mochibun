📲 how to install on your phone

  1. Tap download pack on any card above in your flip phone browser.
  2. Open the downloaded .mochibundle (or legacy .mochibun) or .mochibunled file from your notifications or file manager.
  3. Mochibun pops open a live swatch preview — hit apply and you're all set ♡
