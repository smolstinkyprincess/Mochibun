Mochibun (もちぶん) ♡

A pastel, t9-oriented Android launcher built for the ALT Mive Style Folder(AT-M120)

Download Latest APK View on GitHub
— ♡ Features ♡ —
  • Keypad-First Navigation: Glide across every card and drawer with soft glowing pastel focus rings. ♡
  • T9 Keypad Search: Jump straight to your favorite apps using the 2–9 numeric keys.
  • Virtual Mouse Cursor: Handy system pointer for touch apps, toggled with the side key and customizable with cute .gif or .png sprites.
  • Now Playing Deck: A cozy little media card that appears whenever music is playing.
  • Theme Studio: 4 sweet pastel palettes to match your mood (Sakura Dream, Lavender Mist, Minty Matcha, Milky Peach).
  • Gentle on Hardware: Stripped of heavy GPU blurs to keep everything breezy and responsive.
— ♡ Hardware Specs ♡ —
